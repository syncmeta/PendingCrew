# PendingCrew 当前 Core 入门指引

版本：Core onboarding 1；根据 5daf5a26 当前普通客户端与 Core 数据路径编写。

## 从这里开始

新组织包含“PendingCrew怎么用”、“演示”、“问答”和“子机组”四个机组。“演示”和“问答”属于入门机组，“子机组”同时拥有这两个父机组；两条父边展示的是同一个子机组，不是两份数据。

打开入门机组的“文档”，默认“本群引用”可以阅读这里的资料；切到“机组资料库”可查看本机组原始文档。文档正文与群的引用各自有原权威，解除本群引用不会删除原文。编辑、组合、查看历史与归档沿当前文档面板完成。保存后以当前文档读回为准；版本冲突或提交结果待核对时，先核对原请求，不重复提交。

## 使用边界

创建或阅读这组教程不会自动启动模型、增加待办、向群发消息或唤醒成员。教程机组初始没有工作目录与模型会话。需要实际执行工作时，先由人明确选择安全工作目录，再沿当前成员/会话入口启动；资料所在的 Core 私有数据目录不是模型工作目录。打开文档与重开应用也不会恢复一个已停止的 Agent。

先描述目标、输入、负责人和验收方法，再在实际机组布置任务；工作结果应写明产物、已做的验证与还未解决的问题。待办、需求、工作计划和文档是当前各自的真实资源，不用消息文字冒充完成记录。

## 原公开资料与离线检索

同组的 SKILL.md、INDEX.md、INDEX-v2.md、guide-v1.md、README-source-v1.md、README-public-v2.md、README_EN-public-v1.md、architecture-source-v1.md 保留原始 e427fb2（2026-09-30）来源快照。它们用于历史公开资料检索，其中旧 Runner、白板和工作目录描述不能当作当前 Core 操作说明。当前操作优先读本页与程序实际界面。SKILL.md 在这里是一份资料，没有自动提示词或启动权限。

本机 Core 会在 welcome-crew 下导出可离线检索的只读投影。用 `rg -n '关键词' --glob '*.md' .` 定位相关段落，再打开命中文件。完整八页保持原文件名，当前版本及原文修订/摘要见导出清单。Core 编辑后的资料会得到新的内容版本目录；旧文件包括你自己改过的文件均不会被覆盖。文件编辑不会写回 Core。当前有效阅读仍以正常 Core 文档读回为准。

归档机组或资料、解除本群引用会停止当前导出指针；历史只读导出仍是历史副本。真正永久删除时，只清理可验证由系统生成且未被你改动的导出；你自行改稿或另存的文件保留。重开应用不会补造你已归档或删除的机组、文档和引用。
