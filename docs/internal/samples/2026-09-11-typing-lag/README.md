# 2026-09-11 打字不畅顺（人类 Todo #140）的原始 sample

`sample <pid> <秒数>` 对**界面进程**采的两趟，症状正在发生时采的（纯命令行，没碰窗口）。
结论与归并表在 `../../2026-09-11-typing-lag-profile.md`。

| 文件 | 采样时刻 | 时长 | 主线程忙 |
|---|---|---|---|
| `pc-sample-3s.txt.gz` | 17:17 | 3 s | 77% |
| `pc-sample-5s.txt.gz` | 17:23 | 5 s | 45% |

原来落在 `/tmp/pc-sample.txt` / `/tmp/pc-sample2.txt` —— 临时目录会被回收，所以搬进仓库留档。
只做了 gzip，内容一个字节没改（`gunzip -c` 还原）。

**它们是对照组的「故障侧」，没有「正常侧」**：两趟都在同一个五分钟窗口内采的，
机器不忙的时候没量过。所以「ICU 占 7.1%」这类比例只在那一段时间成立
（第二趟里 ICU 已经掉出前八 —— 那笔开销是阵发的）。

改完要验收时，对**装了新版**的界面进程用同样的命令再采一趟，跟这两份比 `libicucore` 那一栏。
